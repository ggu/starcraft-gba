# Functions the Zerg cartridge runs from IWRAM instead of ROM, ordered by
# measured cycles saved per byte in late three-computer Custom Games.
# See mk/iwram-hot/Makefile and tools/gba_iwram_hot.py.
#
# `limit` is the linker's guard: the highest address the IWRAM code may reach.
# Keep it at or below what `gba_iwram_hot.py check` reports for this ROM
# (stack top, less the worst-case stack depth, less the margin). The build
# runs that check on the linked ROM.
limit 0x03006440

# Call cycles: how many activations of their functions can be live, and the
# fingerprint of the cycle as it was read. When the check reports a changed
# cycle, read the code again before replacing the fingerprint it prints.
#
# Recursion: destroying a Nydus Canal destroys its exit through
# race_nydus_note_building_lost. The pair is unlinked first, so the exit
# does not come back for the entrance.
recursion destroy_building* 2 98d3a072
# The trigger and save layers call one another through ops tables: count
# cache, world adapter, then game services; and save selection, then record
# validators. Each table is bound once to the layer below it, so no function
# here is entered while it is active. The cycle exists only because the
# check lets a pointer call reach every function whose address is taken.
callback-cycle sc64_z8_world_action* 1 b543a92f
