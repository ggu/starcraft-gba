# Functions the Terran cartridge runs from IWRAM instead of ROM, ordered by
# measured cycles saved per byte in late three-computer Custom Games.
# See mk/iwram-hot/Makefile and tools/gba_iwram_hot.py.
#
# `limit` is the linker's guard: the highest address the IWRAM code may reach.
# Keep it at or below what `gba_iwram_hot.py check` reports for this ROM
# (stack top, less the worst-case stack depth, less the margin). The build
# runs that check on the linked ROM.
limit 0x03005d80

# Call cycles: how many activations of their functions can be live, and the
# fingerprint of the cycle as it was read. When the check reports a changed
# cycle, read the code again before replacing the fingerprint it prints.
#
# Recursion: destroying a building with an add-on destroys the add-on from
# race_bc_parent_detach; the add-on has no add-on of its own.
recursion destroy_building* 2 c1c7a2ed
# The trigger and save layers call one another through ops tables: trigger
# dispatch, count cache, then the mission's world functions; and save
# selection, then record validators. Each table is bound once to the layer
# below it, so no function here is entered while it is active. The cycle
# exists only because the check lets a pointer call reach every function
# whose address is taken.
callback-cycle sc64_t6_dispatch_action 1 1ef64d7d
