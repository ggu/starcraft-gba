# Normal Z10 generation-49 predecessor

This is a HOST-authored predecessor and fresh-process reader witness, not a migration, guest, hardware, or campaign-win qualification. The normal producer source was unmodified commit `0c11f91098436a3ec4db423cb4c77718f8af4cd8`; the fixture and public optional recipe were frozen at `56a2846398eecd403f85942c62234a790bad6c44`. The normal Z10 canonical flags included worker cargo and shared transport, without the experimental Scarab or BC energy stages. The producer and reader are separate executions of the same executable. The fixture uses ordinary frontend inputs to select Z10 and invokes the actual game save/load APIs; its HOST setup is not a guest input proof.

The 32,768-byte SRAM image has SHA-256 `7942924a027925426f4876799c613b57acaf1dc12f7dd9f34897bab5deb8368a`. Its first slot has outer tag `0x56435a61`, inner tag `0x52435a61`, payload length `0x3fb8`, and sequence 1; the other slot is erased. Both producer and fresh reader reported mission 21, frame 1, one live Reaver and seven live Shuttles. The normal enum has 49 unit types, with Shuttle ID 48; the subsequently staged Scarab insertion changes that interpretation. The producer reported `RaceSave` size 16,296 bytes, 35-byte unit rows, 28-byte building rows, eight impact slots, and state/unit/building offsets 15,652/4/8,404. These are facts for this exact source and vector, not a universal ABI.

Images, assets, executable and logs remain private. The initial fixture incorrectly attempted nine DOWN presses on a two-row paged menu and failed before producing a save; the corrected fixture selects page 4, row 1, opens the briefing, and starts the mission.

For this exact normal Z10 runtime, the mission descriptor maps town slots 2, 7 and 0 to the collapsed enemy engine owner and human slot 3 to SIDE. This establishes the old port's scoped controller behavior, not N64 behavior or a rule for newer saves and other missions. Unknown or otherwise unvalidated contexts must not be guessed from origin.

A future bridge needs to validate the original outer/inner tags, length, checksum, mission and old-layout semantics before conversion, preserving the original bytes and provenance. It must translate every affected enum-bearing field, including dead unit rows, all queue positions, train type and impact source type, and preserve impact and transport capacity. Only verified legacy-empty Reavers may enter the initial conversion scope; absent staged fields require explicit initialization consistent with their old aliases. The separate compound reader/writer, mixed-format fallback, atomicity, fresh migration, ARM resources and normal enablement remain unqualified. The predecessor is not retagged or rewritten by this witness.
