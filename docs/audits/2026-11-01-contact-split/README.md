# Z7 contact split diagnostic

This is a bounded diagnostic, not a gameplay change or a frame-rate measurement. The measured source was `5e5b89f142383d30a76df370827041c2b2a29703`, based on P8 source `99059f550ebacd8c6ee85cc4a8309083bc04f0cb`. `SC64_DIAGNOSTIC_CONTACT_SPLIT` enables ROM-resident, noinline counters and snapshot bookkeeping. Without that flag, no diagnostic state or calls are compiled. Normal Z7 steering placement and the contact table, cache and memo settings were retained. The diagnostic binary has extra work, so its execution times cannot be used as production FPS.

The physical-button replay used the existing strict trace and driver, without guest-state injection. It checked 135 named trace checkpoints through update 50396 and sampled updates 50001–50900. At each 100-update sample, the state hashes and displayed mode-4 frame and palette hashes matched the earlier uninstrumented normal-placement Z7 run. That comparison covers the sampled fields and frames; it is not full-state equivalence at every update. All 109 pinned input hashes were verified before and after both build and replay; each ran under `/tmp/sc64-native-build-20261031.lock` with more than 2 GiB free. Source was clean and fixed at the measured commit during each job. The generated authored contact table, copied from the existing production build, had SHA-256 `e7993e3efec0582088f4b466368dbf3990cd4896602b01747d76515207b091ce`.

A candidate is classified as position changed when it was alive at consecutive `update_orders` entries and its coordinates differ. The other bucket includes unchanged positions, new or reused slots and pre-filter candidate visits, including the mover itself. Classification is a previous-interval observation and does not predict whether a unit will move later. Geometry counts refer to the optimized valid-class path after its axis rejection, not the invalid-class reference fallback. The traversability count includes all `is_traversable` calls between order-entry resets, rather than only calls attributable to contact. The distribution suggests investigating reuse for stable actors, but the snapshot classification alone is not a correctness condition for a cache.
