# Z7 Transport1 save fixtures

The Z7 candidate tests exercise the current Transport1 namespace by retaining the impact and transport suffix of an existing ordinary save when they replace its RaceSave prefix. The test writer is host-only; non-Transport1 test profiles keep their existing envelope. The positive fixture creates paid Eggs, saves and loads through the ordinary runtime, checks the current envelope and resumes cancellation and paired births. No gameplay or save-format code changes in this branch.

At source `c38d7fd2215f2ecf17de09ac5de97afc626a18c7`, all three fixtures passed under the current canonical Z7 host vector with ASan/UBSan: positive paid Egg save/load, cancellation and both paired births; normal candidate save/load and transactional rejection; and Egg candidate provenance, rejection and enemy Ling bounds. The canonical vector did not include the optional derived-row format. The clean unprepared source boundary, doctor, default build and full default test passed: 935 Python tests (26 skipped) and the native fixture suite, including separate five- and eight-test groups. All 109 pinned inputs, auxiliary input and named sidecars remained unchanged. Logs: `/tmp/sc64-z7-transport1-fixture-qualification-20261101`.

Before these test-only fixes, the older fixtures wrote a legacy `SAVE_VERSION` envelope and failed to load it under the canonical Transport1 reader. An earlier probe fixture also required an unavailable legacy Z6 bank; the successful checks use the canonical bank. These host candidate tests do not establish compatibility with guest SRAM or other save namespaces. The shared-Egg runtime experiment is separate and is not included in this branch.
