# Target owner-list link storage

The owner-index links are signed 16-bit indices; the heads remain `int` and the list terminator remains -1. A compile-time bound requires both capacities to be at most 32768. Lists are still rebuilt in the same order and invalid owners still select the scalar path. No save data or persistent game state changes.

Qualification used runtime source `c98bac58`, against baseline `8a2bcf11`, with the same 1,958 prepared input files verified by SHA-256 before and after production builds. Four independently built host fixtures used the same test source on each runtime. For Terran, Zerg, Protoss and Showcase, 10,000 rebuilds exercised ordered membership, nearest-enemy queries, invalid unit/building owners, terminal slots, and (where compiled) a hidden Scarab with an invalid owner. The recorded ordered list/query integer streams matched byte-for-byte between baseline and candidate: 4,253,640 bytes for Terran and 5,841,624 bytes for each other profile. To repeat with authorized prepared inputs, build `make test-sc64-owner-lists` on each runtime using this fixture, then set `SC64_OWNER_EXACT_TRACE=1` when running each `build/test-sc64-owner-lists-{terran,zerg,protoss,showcase}` binary and compare corresponding streams. These tests cover the fixture inputs rather than every possible game state.

All six normal product builds and their link guards passed. The Z9 and Z10 BSS end changed from `0203dff8` to `0203dcd8`, yielding 808 bytes below the `0203e000` guard instead of eight; their IWRAM end changed from `03004bf0` to `03004bf8`. The 800-byte BSS reduction is measured in these builds; other profiles have different capacities. All six ROM binaries changed. The standard unprepared source-tree check, doctor, build and tests passed, as did prepared `make unified test-unified`. The unprepared checkout had no imported `.local/sc64` inputs.

A normal-P10-flag replacement-loop replay of the same ordinary P7 tape compared 958 advancing updates and matched all 90 sampled state/pixel/frame checkpoints. Full-loop cycles were 2,151,595,981 baseline and 2,151,033,780 candidate (means 2,245,924.82 and 2,245,337.97; 0.026% fewer); peak cycles were 3,958,804 and 3,955,676 at call 8347. This is a negligible timing change in one emulator window, not a hardware playthrough or 30-fps qualification. The timing reader checks required ELF symbols before replay, and the earlier failed attempt with a mismatched stage-counter reader was retained separately and excluded from the results. No hosted Actions were run.
