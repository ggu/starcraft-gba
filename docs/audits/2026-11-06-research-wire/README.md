# Experimental shared research journal admission

This is a default-off experiment, not a research feature or release format. It adds no menus, combat routing or paid jobs. `SC64_EXPERIMENTAL_RESEARCH_JOURNAL` requires the normal shared-transport/worker/impact save path; unsupported actor-stage formats fail compilation. The experimental transport tag toggles bit 31 of the current outer tag, leaving the inner `SAVE_VERSION` and normal record size unchanged. Both normal predecessor tags remain recognized. The flag permits legacy reads and writes a new-tag record, so an older build will not understand the new slot. Do not use it with real saves or ship it without a separately reviewed namespace and compatibility policy.

The writer validates normal state first, then packs the 96 research bits into reserved building padding in detached `race_impact_record`. The selector validates the new tag, current inner version and transport/impact payload, then decodes the levels and clears reserved bits in that detached candidate, before all existing preflight validators. A `RaceLoadPlan` keeps the eight-owner values until the selector revalidates the original SRAM slot; publication occurs only after selection. Legacy records produce zero levels. New-game initialization clears the experimental live state. Existing 5-owner custom and 8-owner campaign level domains are checked; campaign/actor ownership, active research jobs, and playable upgrades are not implemented by this experiment.

No second full record buffer is allocated. Encoding/decoding traverses the existing detached rows in place, using 12 packed bytes and a 48-byte candidate level object; the load plan also stores 48 bytes. These are source-level sizes, not a measured call-chain bound or dynamic stack high-water.

Focused synthetic-level actual-engine P10 and Z9 HOST fixtures exercise campaign and custom contexts, old-tag load, new-tag round trip, an invalid newer but checksummed record falling back to the predecessor without SRAM mutation, rejection of custom owner 5, and eight pending impacts through save/load. They use ASan/UBSan and actual release profile flags plus this explicit experiment. The old-tag record is constructed by retagging a zero-level candidate, whose payload is identical to the old encoding. These fixtures do not establish ordinary research gameplay, authentic campaign-origin research levels, complete all-mission migration, any one/two-Yamato-shot combination, or hardware correctness. Compile and run with `make -f Makefile -f tests/sc64-research-journal/Makefile test-sc64-research-p10` or `test-sc64-research-z9`, supplying the known private input banks and delivered audio directory; serialize native work with the shared lock.
