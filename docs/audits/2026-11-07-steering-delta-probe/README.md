# Experimental blocked-steering cost delta

The default-off `SC64_STEER_COST_DELTA_PROBE` replaces each squared-distance ranking in the existing blocked `SC64_CONTACT_CACHE` steering loop with the algebraic delta from the mover's common squared distance. It retains the original eight-direction order, strict tie comparison, collision mask, terrain queries and scalar fallback outside bounded nonnegative coordinates and speed. It does not change clocks, actor limits, path state or save data.

At source `2956ad04`, a standalone ASan/UBSan oracle checked 12,000 edge/random input sets against all 256 direction masks (log SHA-256 `052b1066eff8a2ae59d9cf79c938c221e174ba512f0e9c3700aa7d5e26024311`). The actual P7 contact-cache HOST fixture produced matching neutral and attack-move traces with the probe off and on. A separate HOST-only scalar winner assertion checked 111,557 reached blocked-steering decisions; the OFF/ON logs were `b4984d8cd66d473becc320dfd60ecdc44a145da4993909eb352a5f9adc7ad5f5` and `535bc303007089a643ac6e2eb79b51e332ea213b6a1b129dba44c03bac73209d`. The first attempted HOST fixture compile used incompatible old collision-cache and new contact-cache flags and failed before execution; its log remains in the ignored qualification directory. The corrected fixture used the contact-cache vector.

Normal P10 OFF/ON links passed existing guards. The OFF ROM exactly matched the released 32 MiB `70e9800f7d9803d8a70a05a417b1b7939650999800010efdd0153ebc1ade0415` ROM; ON ROM SHA-256 was `3172e18a7b76d55d5c8866bc6eb46855eaf8e44f5fcc9184e1f8c0fe8bf4c4ca`. EWRAM margin remained 19,992 bytes, while IWRAM margin fell from 2,056 to 1,800 bytes. ARM disassembly showed the original compiler already inlined each scalar cost as a short multiply/multiply-accumulate sequence. The probe adds guard/setup work, branch-heavy per-direction scoring and a scalar fallback; the full `move_toward` body grew from 350 to 414 instructions. The available assembly evidence does not justify a performance replay or promotion of this shape. No cycle reduction, hardware speed, every-frame parity or complete-game claim is made.
