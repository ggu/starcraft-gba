# Shared walk-cycle integration and packed-pose experiment

The source-walk branch is merged into shared source `53f1668` with both histories preserved. Walk poses remain presentation-only. The `CANONICAL_WALK_WORDS` sidecars default to 1 in the four canonical products and can be disabled for comparison; they cover raw IDs 0, 32, 37, 38, 41 and 65 and leave every other unit on the same complete walk-animation fallback. The sidecar producer derives only from the prepared walk/facing headers, writes ignored managed output, and validates their pairing. Newly prepared walk banks embed the facing-header hash; the historical unmarked pair is accepted only by its two exact hashes. The mode and input/tool content participate in the existing same-tick rebuild key. `dev prepare` derives the optional bank, while prepared walk/facing files are not re-extracted merely because a checkout has newer tool timestamps.
