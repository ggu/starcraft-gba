# Fractional damage storage: bounded representation experiment

The standalone helper stores the complete product of a 0..1279 existing phase and independent 0..255 HP and shield fractions in 27 bits. Its test enumerates all 83,886,080 possible words, independently checks each channel against division and remainder, round-trips every value, and checks rejection leaves outputs unchanged. The phase is an opaque value: this does not establish that any live alias can be repurposed. No runtime state, wire tag or save selector uses this helper.

The actual six-profile journal audit in `docs/audits/2026-11-06-research-padding/README.md` records a 16,368-byte maximum, a 16,296-byte Z7/Z9 RaceSave, and an exact fit with eight impacts and the 16-byte transport trailer. Its 160 compact building rows provide 1,120 reserved bits; research levels consume 96, leaving at most 1,024 bits (128 bytes), subject to every other layout and validation invariant. P10's 160 typed building rows provide 800 padding bits; after 96 research bits, at most 704 bits (88 bytes) remain. There is no assumed room in unit rows. Both previous-tag readers and all legal impact/transport combinations must remain intact.

A naive two-byte fraction array for each of 240 units and 160 buildings requires 800 bytes, more than the bounded stage's reported 732-byte Z9 EWRAM guard margin, before code, stack, alignment, or any other state. The 27-bit word does not solve this: replacing the existing 11-bit phase needs 16 additional bits per represented actor, and existing phase storage has other actor-specific meanings. The calculation treats all fractions as independent; it does not prove every such combination is reachable, so it is not a general impossibility proof. A smaller production codec would need a proved reachable-state invariant or a lossless re-encoding of other fields, plus exact profile-specific maximum-size and memory proofs. It must retain legal old HP values and dead-row data and coexist with research padding, actor aliases, transport and all eight impacts. No fixed append, discarded fraction, narrower existing field, or larger scratch buffer is authorized by this experiment.

`cc -std=c11 -O2 -Wall -Wextra -Werror tests/sc64_q8_fraction_word.c -o <output>` and the test executable passed under the shared native lock with the 4 GiB reserve. This establishes only the standalone representation; no game damage path, SRAM journal, fractional regeneration policy, GBA link, old-tag migration or physical parity is qualified.
