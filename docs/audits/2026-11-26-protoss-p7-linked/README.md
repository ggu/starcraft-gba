# Standard Protoss Homeland from the P6 victory

The standard Protoss10 ROM loaded the earned P6 SRAM from HOME with L.
A on RESULT entered Homeland, mission slot 26, at frame zero. The
ordinary button replay won at frame 41,224 after 42,106 physical calls.
All 43 named checkpoints and ten field dialogue pages matched the
controller. The three source heroes survived, faults and unsupported
actions were zero, and the completed mask was `0x7c0000c`.

A fresh HOME L restored the winning world, mission runtime and
completion mask. It exported SRAM byte for byte. The P6 bank remains
at sequence 6 and the other bank contains the P7 victory at sequence
7 with a verified checksum.

The current P7 controller capped out after 180,000 calls. It destroyed
one Nexus but left most fighters around the home Gateway cluster. The
replay used the controller policy from `5d4376b4` on the standard
cartridge's current engine. The [controller patch](controller.patch.txt)
adds the current render cadence, field dialogue buttons and update
indices to that historical policy. Optimized and ASan/UBSan builds
generated byte-identical tapes and dialogue logs. The main controller
source in the repository remains available for its existing routes.

In an isolated prepared worktree for the P10 build at `82fc1a73`, stage
the old controller with the included patch:

```sh
git show 5d4376b4:tests/sc64_p7_campaign_run.c > tests/sc64_p7_campaign_run.c
git apply --unidiff-zero "$P7_CONTROLLER_PATCH"
make build/test-sc64-p10-p7-normal-home
./build/test-sc64-p10-p7-normal-home p7-home.jsonl 2> p7-pages.log
```
