# Protoss custom death geometry: source-only inspection

The shipped normal source-art path selects a death record by the dead actor's raw identity, then blits each source layer using its canvas center, frame offsets and layer offsets. It does not use the authored fallback's radius when the source record is valid. No native death presentation was observed in this audit.

The private prepared P10 death header SHA-256 is `09c43c6a26f3dcef6303dedf13118a432100fde05b81296c8ac788cf46dc11a6`; its body header is `db9210845410f222d50d4e18247932069b4cf508d8964a702abc40ac741254c5`. The private death manifest attributes its actor-to-image mappings to the authenticated USA source's unit, flingy, sprite, image and IScript tables. Probe 64 maps actor image 137 to explosion layer 213, not building layer 215. SCV 7 maps to layer 332. Zealot 65 uses collapse 151; Dragoon 66 uses collapse 122 and remnant 124; Zergling 37 uses collapse 54 and remnant 57; Hydralisk 38 uses collapse 29 and remnant 32. Representative Nexus 154 and Pylon 156 use building burst 215; Hatchery 131 and Creep Colony 143 use burst 60. The listed layer offsets are zero.

Selected body rectangles versus peak death-frame rectangles are Probe 16×15 versus 51×53, Zealot 10×17 versus 28×34, Dragoon 20×26 versus 44×36, Zergling 11×13 versus 34×27, and Hydralisk 14×23 versus 47×36. Pylon 30×40 and Nexus 74×68 both use a burst reaching 116×91. These are cropped frame rectangles, not alpha-exact pixel bounds; actor-facing and animation frames can vary. Probe's 64×64 death canvas versus 16×30 body canvas makes the large perceived ratio plausible, but neither these dimensions nor the source resource identities prove how N64 presents or scales the effect. The importer retains source GRP rectangles and canvas dimensions, and no incorrect unit-to-building explosion routing was found among these examples.

A useful next comparison is a fixed actor with its actual selected-facing body and death frames composited at the same real world anchor, including frame indices, offsets and timing, paired with a separately authorized ordinary-input native worker-death observation. Do not infer the intended native ratio or shrink source art based on this inventory alone.
