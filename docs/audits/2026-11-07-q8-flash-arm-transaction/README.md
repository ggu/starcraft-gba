# Experimental Flash save transaction

Source `87de551e` stages transaction entry and cleanup around the real ARM game save/load calls, including title loads. It masks IME, rejects DMA channels not matching the imported Direct Sound setup, stops its timer and FIFO DMAs, retains mixer and decoder state, then restarts streams at their known buffer boundary and restores the prior timer and IME policy. Reinitializing the FIFO boundary may repeat or omit a short audio fragment; continuity is not qualified. Pending IRQ flags are not cleared. A timed-out Flash transport remains sticky and no reset or bank command is attempted by cleanup. Normal builds do not include this transaction.

Callback gate tests and tests of the same audio register sequencing against fake registers passed under ASan/UBSan. They cover nested transactions, failure before mutation, a pre-disabled IME, normal quiescence/restart, disabled DMA and unknown DMA rejection. The guarded P10 ARM link passed with all 593 retained input hashes unchanged: EWRAM end `02039484`, IWRAM end `030047f8`, margins 19,324 and 2,056 bytes respectively. P10 ELF SHA-256 is `0de174408b9776e2b320f7ba603a71d5b0fe6c35a33deae77227201dc111da9a`. The equivalent six-profile margins have not been measured on this successor. Logs and private inputs remain ignored.

These are source, fake-register and link checks, not proof of real audio timing, hardware register semantics, Flash device polling or power-failure behavior. An actual ordinary-input unforced-mGBA save/load, interrupted/failing operations, device timing and cartridge testing remain open. No production feature, save signature or format is enabled by this branch.
