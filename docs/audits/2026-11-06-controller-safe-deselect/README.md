# Controller producer deselection after queue cancellation

Source base `ab70bdd23e752e3c3c1390eba85a6cc7d4e102f2` includes ordinary producer L cancellation. Older adaptive campaign controllers used L when their intent was to leave a selected building or begin cycling units. On a selected queued producer, that now cancels the paid front item instead of merely leaving selection. These source-only changes use SELECT to leave a building first, retain L for unit cycling and retain deliberate L-drag selection gestures. Z7's empty-box deselection avoids L when its starting selection is a building; the shared Z8/Z9/Z10 helper uses SELECT to leave a producer.

The runtime L cancellation and refund behavior are unchanged. `tests/sc64_zerg_controller_safe_deselect.c` directly exercises the shared late-Zerg helper on a queued Hatchery and then verifies deliberate L still cancels; its authored setup is a focused controller-input fixture, not a mission run. The replay-parser Python suites remain useful for trace validation but do not qualify controller strategy or wins. Existing historical tapes are not regenerated by source edits. Every affected campaign controller needs a fresh ordinary-input rerun and any claimed physical replay must use a newly retained matching tape; past wins and timing do not automatically transfer.
