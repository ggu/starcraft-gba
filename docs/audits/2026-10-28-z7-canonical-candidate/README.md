# Z7 canonical candidate wiring

Status: candidate product wiring only. This does not promote Z7 into the
default Zerg ROM.

## Product identities

`zerg` and explicit `zerg-z6` continue to build the six-entry `SCZ6` ROM and
use the generation-32 Z6 save identity. The new `zerg-z7` profile builds a
separate `SCZ7` ROM, uses the authenticated Z7 scenario, and keeps Egg
production enabled for the generation-36 save identity. The earlier
`zerg-z6-probe` route remains available under its probe ROM name.

The Z7 candidate uses `ZERG_Z7_CANONICAL_FLAGS`, based on the full-render Z7
profile and its existing Z6 inherited sprite bank. It retains full drawing,
minimap, facing, weapon, attack and death presentation; Z7 source sight,
Scourge combat, defense targets and the completed Z7 campaign mechanics; plus
the qualified steering list, reachable formation, started-trigger pruning and
route decay frequency. It does not enable the derived-save profile or contact
cache features.
