# Z9 custom research journal HOST qualification

This is a constructed-state, test-only qualification of the existing default-off HOST experimental job journal, not enabled GBA research or an ordinary-input game. Runtime source is `c98542e29f20cb5de05be6df6f80daad917ca334`; the test-only successor `2ed1192c6502569a3e8119b1b92003fb7b854fb9` resolves the Archives fixture type from raw 165 so the Z9 profile does not require the P10-specific enum.

Separate ASan/UBSan HOST processes used the normal Z9 profile and the same 592 hash-verified retained inputs, including the current audio bank. A genuine normal writer compiled from current main `a257a5c4c8d7fc974d460d2ac93c803182c83eba` without either research flag produced 0x43 SRAM SHA-256 `56dd6803e220e5d867b7798c41f129286d11a5a861312b4ef9d336bad39cb382`. The 0x44 predecessor SHA-256 was `83b760ed5c51fedb364f3937ac268e05f457ada07e6e48b2995f1c7153dfe1c0`; the 0x45 active-job journal SHA-256 was `171f88da2773aa7109e8b7339f461eb77ca708b53acd511f72078fdab2c3c9c6`. Each loaded in a separate experimental consumer process. The old writers exercised a real Gateway queue, destruction and reused live/dead Forge slots; old inert queue bytes survived and the live Forge could start paid research. New active jobs resumed, advanced and canceled with the original wallet restored.

The genuine 0x43/0x45 and 0x44/0x45 mixed records also loaded the newer active job. For each pair, copies with either a bad newer checksum or a checksum-valid invalid newer custom bot count selected the untouched predecessor in a fresh process. The older slot remained byte-identical; the test did not write either input SRAM file. Both 592-file input sets were verified before and after. Logs and private SRAM remain ignored in `.local/qualification/`.

This does not authenticate historical payment cryptographically, qualify all possible corrupt records, validate campaign contexts, establish native research behavior, or prove a production GBA memory design. In particular, this test covers the former HOST receipt-array stage; the separate bounded-row implementation requires its own qualification.
