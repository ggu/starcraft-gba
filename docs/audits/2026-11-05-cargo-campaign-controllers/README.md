# Cargo-enabled Z7 and Protoss campaign controllers

On `ef4e6437`, cargo-enabled canonical controllers failed Z7 at the existing 200,000-call limit with five enemy buildings, P8 in defeat at frame 20,617, and P10 without a win at its existing limit. With the same source and freshly prepared inputs but `CANONICAL_WORKER_CARGO_FLAGS=` the original routes won Z7 at call 141,913, P8 at frame 96,889 and P10 at frame 72,441. The first Z7 comparison without the canonical policy is excluded.

The Z7 controller now permits loaded idle Drones to receive ordinary mineral orders. The P8 and P10 controllers do the same for idle workers and skip the obsolete gas-order-and-STOP workaround when cargo is enabled. That workaround assumed those inputs discard cargo. Cargo-off routes retain their prior behavior. These changes use ordinary input through the game update, not world writes; no win checks or limits were relaxed.

With the cargo flag on and the same inputs, `make -k test-zerg-z7` passed: Z1–Z7 controller checks, Z7 normal-menu save and invalid-candidate checks, the 234-configuration startup/save matrix and 18 skirmish matches. Z7 won at call 175,455, frame 173,807, with zero faults. The skirmish controller lost all 18 matches, which the matrix accepts and does not establish balance. `make -k test-sc64-protoss-px` passed all ten ordinary-input controller tapes and host replays; P8 won at frame 92,377, P10 at frame 145,833. P8 host save continuation matched 64 checkpoints; P9 host continuation also matched. These are single host routes, not ARM replays, physical hardware results or native AI parity.

The Z7 host-only candidate writer now preserves the opaque save envelope and isolates each malformed candidate from an older valid record. After an invalid load and live-state checks, the fixture asserts that the production writer refuses the committed invalid record. The helper then prepares the next independent case. Production save selection and refusal remain unchanged.

Tests used fresh release inputs copied from the `6417737c` package preparation. All 1,734 `.local/sc64` files listed in its `MANIFEST.json` matched SHA-256 before the runs; the manifest is in the local ignored release package `.local/releases/20261104-6417737c-race-campaigns`. Native runs used the shared flock and a 2 GiB free-space guard. Controller and full-suite output was retained locally under `/tmp/sc64-cargo-campaign-*.log` and `/tmp/sc64-cargo-final-*.log`.
