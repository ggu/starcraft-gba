# Detached Scarab candidate experiments

This is an incomplete HOST-only checkpoint, not a guest journal or service.
Existing Scarab/worker-cargo, Egg/Scarab and Guardian/Scarab fences remain. The
old standalone Scarab stage now carries selected tag-pair authentication in a
candidate-local context and converts legacy Reaver fields in decoded Unit
temporaries instead of rewriting its candidate rows or inner version. The
stage still rejects outside children and pending impacts. It does not preserve
or admit unqualified old HOST-only combined formats.

A separate `SC64_SCARAB_STABLE_ROSTER_HOST_STAGE` experiment keeps existing
legacy and custom Egg IDs before the new Scarab ID, and explicitly forbids the
old Guardian stage and Scarab journal. Its compact/ZP/typed codec experiment
uses feature bits to admit raw-85 child rows only with the Scarab feature;
no new selector or writer publishes those rows. Z7 derived codec and the final
Egg/Guardian/Scarab roster, plus workers, Carrier, trigger and impact shared
validation, remain to be completed. Existing Guardian prototype ordering
shifts appended Egg IDs; a final combined layout must put real Egg IDs before
new Guardian/Cocoon/Scarab IDs and use an independently collision-audited tag.

With the native lock and every verified prepared input marked old to Make, the
standalone detached fixture passed Terran and Zerg compact codecs and, after a
fixture fact-generator flag correction, P7 typed and Showcase codecs. These
synthetic probes disable transport/cargo *only as isolated fixture vectors*,
not as changes to product flags or fences. Initial P7 attempts failed on a
fact-table flag mismatch; their logs and generated inputs remain under ignored
`.local/scarab-context-*` and `build/generated/scarab-context/`. The P7 and
Showcase run overlapped source-only stable-roster edits that are disabled in
that vector; repeat on a frozen final tree for release claims.

The separate stable-roster Terran detached compact-codec fixture passed a
constructed paid parent/hidden child candidate: feature authorization allows
child decode, absence of the feature rejects it, and failure/candidate bytes
remain unchanged. It is not a journal selection or full graph test. The first
invocation specified the wrong Makefile; the second had a fixture include/main
error. Both failed logs are retained in ignored `.local/scarab-egg-*`.

A real predecessor writer was compiled against the untouched base
`19435672eb922d932d0f2f13ae9858f4b16785e9` and wrote a paid custom Egg together
with ordinary Reaver and Shuttle to private HOST SRAM. A separately compiled
current stable-roster Terran reader loaded all three, normalized the empty old
Reaver, and both processes reported legacy bound/Egg IDs `44/44`. Logs and
private constructed SRAM remain ignored in `build/scarab-egg-prior2/` and
`.local/scarab-egg-prior-terran-expanded.log`. This proves one host codec and
selected custom configuration only, not older formats in every product, a
full fallback/rejection transaction, or original N64 SRAM compatibility.
Every one of the 1,959 copied private input hashes matched after the initial
runs. No N64 gameplay observation, ARM link, runtime performance or common
service qualification is claimed.
