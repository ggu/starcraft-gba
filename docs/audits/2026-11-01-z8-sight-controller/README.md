This source-only candidate is based on experimental `443a905`, including Z8's source-derived sight and exact spans. It adapts the earlier southern-priority controller, whose prior results belong to older source and are not current-source qualification. The controller reads game state as an oracle and issues commands through normal gameplay buttons; it is not a no-oracle human-play demonstration. It changes no engine state, mission objective, actor statistics, upgrades, wallet or AI. It has not been run.
