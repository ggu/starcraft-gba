# Early steering point experiment: rejected

This default-off experiment checks the lowest-cost terrain-valid steering direction with the normal point-collision predicate before falling back to the existing eight-direction contact mask. It preserves the current strict cost comparison and iteration order. The blocked original point is reused only when its coordinates match exactly; a snapped step can differ from every full-speed direction. No actor limits, cadence, save state, or memory guards change.

At source `568584146f8b95e940c74984a9ec35b5e942c119`, the independent scalar collision/winner oracle passed 225,890 checks, including explicit tie, snapped-step, blocked-terrain, actor-record and cached-mask cases. Existing P10 dense contact tests passed with the experiment both off and on: each included 4,138,459 point checks, 636,686 active-mask checks, 130,616 inactive-mask checks, 71,992 mutations and zero failures or unhooked memo-world changes. These are focused host checks, not all-product gameplay qualification.
