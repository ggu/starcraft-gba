# Custom sight and fog source investigation

This is a source/data audit and bounded callback observation. It does not establish exact native visibility geometry, audio, timing, remembered resource behavior or physical GBA performance.

The authenticated owned USA ROM SHA-256 `e7d21880c13953b45b8f8db6b2b6cfa02daa29d35b23799a967e96f21001b020` has unit data BOLT `00C/001`, SHA-256 `54356d7585c66cd463346996444fd208336eaacf6335d30eb2688aa73c9cb2df`. The 228-byte sight column at offset 8172 matches every entry in the checked-in `sc64_source_sight_tiles.h`; pinned OpenBW `data_loading.h` identifies the column and `bwgame.h` converts source tiles to 32 pixels. Selected authenticated values are SCV 7, Drone 7, Probe 8, Zealot 7, Observer 9, Nexus 11, Pylon 8, Gateway 10 and Photon Cannon 11 tiles. The GBA coordinates use half scale, so nominal radii are 16 GBA pixels per source tile. OpenBW also applies four source tiles to unfinished non-morphing grounded buildings, preserves a morphing building's source type, and has blindness and upgrade cases; these source facts alone do not prove the N64's exact reveal mask.

The delivered P10 custom vector defines `SC64_ZP_CAMPAIGN_ACTORS` but not the T4 or Z7 source-sight flags. Its `sc64_zp_actor_sight_source_pixels` and building counterpart cover specific extended campaign actors, not ordinary Probe, Nexus, Pylon or Gateway. Those normal types therefore fall back in `sc64_visibility.h`: the Probe's visible radius is 56 GBA pixels and exploration radius is four GBA tiles, versus source-nominal 128 pixels/eight tiles; the Nexus uses 112 visible pixels but only three exploration tiles, versus source-nominal 176 pixels/11 tiles. Other standard actors similarly use generic defaults. Exploration and current visibility use different raster paths, so neither a generic game.c fallback nor one nominal radius establishes the shape of the native boundary.

Custom init clears explored and visible grids, then reveals from friendly live sources. Authenticated Blood Bath BOLT `008/04F` CHK SHA-256 `d94fe779016064030ed693351a64c8adbb5eb0c1f50aab50ddc6f7bb8f58201d` contains a 64×64 MASK consisting of 4096 bytes `0xff`; pinned OpenBW's `MASK` loader and inverted owner-bit query interpret that as initially unseen. The custom importer does not carry a MASK; the all-hidden start is consistent with this particular source map, not a general claim about other maps or campaign masks. Outpost is authored and has no corresponding authenticated CHK identity here.

The current renderer's static-object key and draw path use `currently_visible` at the mineral or geyser center (`game.c` around `sc64_static_objects_key` and `draw_map_static_objects`); an explored but currently unseen resource is not drawn by those paths. Whether the native game remembers resource art after sight leaves remains unobserved and is not changed by this experiment.

A fresh isolated callback run used the pinned ares v148 source revision `0aafd85789215e84e1e43415c07d4c88461b7899`, binary SHA-256 `45d4dadbe233071efa6b6565bb16fa17809323609f5e27ff66417ecdadc974e5`, and the ordinary input startup previously used for Melee/Challenger, human Protoss against computer Zerg. The exact selected map name was not verified. The pan skipped the boundary; no previously seen remote resource was sampled after its vision left. One later capture contains scanout-like colored strips, so those artifacts cannot be interpreted as terrain. The process exited 0 in 61.742 seconds, with eight frames totaling 4,915,200 bytes, checked inputs unchanged, and command log SHA-256 `6ee8acb066ea7f8cba70ed3a3d65255414ff12319a25cf602594268774800e65`. ## Default-off candidate

`SC64_SOURCE_SIGHT_ALL_RACES` is an isolated default-off experiment. It retains existing mission-specific source providers first, falls back to the authenticated-equal raw sight table, uses existing source-radius row spans when enabled, records newly visible cells as explored without a separate larger tile-centered sweep, preserves incomplete and known morph predecessor keys, and aligns P7 owner optical sight including a 176-pixel building cull. It does not change the custom initial mask or resource draw rule. P10 and Z9 feature-on HOST ASan/UBSan fixtures compare full current-visibility grids against independent circle oracles for several Protoss, Terran and Zerg units/buildings, overlapping sources, edges, movement, dead sources, explored superset, incomplete/morph keys, and P10 owner separation. Z9 does not map raw-12 Battlecruiser and explicitly skips that witness. Early fixture-only Z9 compilation/mapping failures are retained in ignored logs.

At candidate `67a78f89`, before the later feature-on exploration refinement, an exploratory P10 ARM link with the flag off produced the same objcopy binary as the already packaged qualified P10 baseline, SHA-256 `28527458d34b9b25289c74bc6397203de1d4081e35211f95e74b3927e3906004`. The corresponding feature-on P10 link also passed unchanged linker guards: IWRAM end `0x03004ba8` (1,112 bytes remaining), BSS end `0x020391e8` (19,992 bytes remaining). This is not six-profile qualification, a performance measurement, an actual GBA/native paired fog comparison or authorization to activate the flag. Additional source-radius geometry, incomplete/morph, owner/detector, save/load, full product matrix and representative crowded-scene performance checks are needed before activation.

Subsequently, feature-on candidate runtime source `592edaa78b509d8562394316edbea702cc6c3b6e` passed all six unchanged guarded links: Terran, Z9, P10, Showcase, Z7 and Z10. Per-translation-unit compiler scans and pinned inputs yielded 976 hashes unchanged before and after; the manifests both hash to `7956324b265f3b92f9c46f04db8d20f32a52932228bb911c217dbea07d8dcfd9`. Test-only successor `8216e00a09c05bc157901a55cbcbeb4508f699db` passed the P10/Z9 focused fixtures again, including a real custom save/load with regenerated visible and explored grids matching their saved states. Exhaustive raw-to-type witnesses found zero sight differences for mapped actors in P10, Terran and Showcase. Z9 had one retained mission-provider exception: neutral raw 173 Khaydarin Formation reports eight source tiles in the existing campaign fact provider, while authenticated units.dat reports ten. The candidate deliberately preserves that override; the witness does not establish whether that objective prop can contribute optical sight.

The existing ordinary-input P7 busy tape compared the same new sight policy implemented with scalar circles and with source spans at runtime source `8216e00a`. In 958 advancing observations, sampled world state, visible/explored grids, complete displayed indexed framebuffers/palettes, timeline, counts and modal handling matched. Scalar mean was 2,907,805 cycles and p95 3,370,922; span mean was 2,307,871 cycles and p95 2,809,225, respectively 20.63% and 16.66% lower in this bounded replay. A separate older, smaller-sight baseline had mean 2,294,431 cycles; the new span mean is about 0.59% higher numerically, but the sight and world visibility differ intentionally, so no old/new state equivalence is claimed. This one P7 replay is not a physical-device or general 30-fps result. The flag remains off pending review and any additional required checks.
