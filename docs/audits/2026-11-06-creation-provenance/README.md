# Shared creation provenance candidate

This candidate fills an unknown `raw_owner` only for a newly created actor in the shared worker-foundation commit or ordinary producer completion. Existing mission-specific spawn hooks take precedence. A campaign creator's raw slot is accepted only when the active descriptor's existing `race_campaign_owner` mapping agrees with the live owner. For a human-controlled creator whose retained origin does not map to SIDE, the descriptor human slot is used only if it maps to SIDE and no second source slot maps to SIDE. Ambiguous or unsupported provenance remains unknown; creation itself is not denied. Custom mode is unchanged and uses its compact owner context.

This is not a universal current-controller identity. P1 and P4 rescue deliberately preserve pre-rescue `raw_owner` on existing actors for trigger semantics. The candidate never rewrites them. The P5 product hook has a fixed reverse map from compact owner to a source slot even where multiple source enemy slots share a compact owner; this candidate intentionally does not override that existing hook. Additional source-aware constructor context and transfer/save validation need review before attributing P5 AI products or enabling owner-specific research on ambiguous actors. Z5 has multiple source SIDE mappings and does not receive a guessed fallback.

The source-backed P1/P3 host fixture uses the real campaign initializer. P1's authenticated source has no placed raw-64 Probe: the fixture moves an existing SIDE unit into the documented rescue region, checks the rescued Nexus and Pylon retain raw owner 1, adds a completed Pylon because the rescued force is over supply (44/34), grants resources, queues a Probe at the Nexus, accelerates its queue timer, and starts a Forge with the new Probe. P3 uses its placed human Probe. Both test the Forge source slot and save/load; a separate Dragoon completion check seeds a queue rather than exercising queue admission. P4 checks contact rescue retains raw origin. The T3 fixture seeds two near-complete paired-product queues for source enemy slots collapsed to ENEMY and checks the ordinary completion path plus custom owners 0–4 through the helper; it is not queue-admission or a full AI-town proof. All fixtures use authored test resources, positions or timing and are not controller replays.
