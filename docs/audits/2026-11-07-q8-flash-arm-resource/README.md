# Q8 Flash ARM resource probe

This default-off probe compiles the real detached game save and load bridge with the experimental Flash1M window transport and journal. It is a resource experiment, not a playable or hardware-qualified backend. The first 32 KiB is never programmed or erased; an existing legacy winner blocks a new write rather than silently migrating it. Unknown committed layouts remain protected by the underlying HOST-tested ownership checks. The bridge accepts only Protoss custom game state, and its ARM I/O rejects calls unless paused, IME is off and both audio DMA channels are disabled. In particular this does not implement ordinary title loading or audio/IRQ quiescence and restoration. Poll bounds and 4 KiB sector geometry are not a device qualification. The explicit probe emits `FLASH1M_V103`; normal builds retain `SRAM_V113`.

On source `417dea6c`, all six canonical product vectors plus Q8, research jobs and the actual Flash backend linked under the existing guards; 593 retained private input hashes matched before and after. These are link results only, not six-profile game or save qualification. In bytes, EWRAM/IWRAM guard margins were P10 19396/2056, Terran 28408/2856, Z9 196/1936, Showcase 28740/1464, Z7 2356/1024 and Z10 196/1936. The 196-byte EWRAM margin in Z9 and Z10 leaves little space for additional backend state. Logs and maps are private ignored artifacts in `.local/probe` and `build`; no assets are committed. Builds emitted existing compiler and Make warnings; no claim of warning-free compilation is made.

P10 compiler `.su` reports 704 bytes for `race_save_game`, 1288 for `race_q8_flash_write`, 160 for detached candidate preflight, and 712 for `race_load_game`. Z9 reports 1408 and 760 bytes for its save and load functions. These are individual static frames, not an aggregate call-chain bound or measured runtime stack high-water. No new cartridge, emulator, full-game controller, recovery, power interruption or audio continuity test was run. Normal product activation requires those checks, device-specific flash geometry and timing, safe complete transaction ownership and restoration of IRQ/DMA/audio state, and explicit migration semantics.
