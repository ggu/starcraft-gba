# Optical source-grid probe

`SC64_OPTICAL_GRID_PROBE` is default off. It uses the already-built target index for optical-source visibility only during the pre-orders Arbiter source tick, with the existing inclusive sight broadphase, exact radius/circle and source-mask rules. Source masks use the existing snapshot arrays indexed by slot; no new BSS is added. Index-inactive, out-of-world target and optically eligible hidden-Scarab cases fall back to the original scalar traversal. The target index itself fails closed if an included actor has an invalid owner/position or the grid is oversized. Normal gameplay cadence and detector rules do not change.

At runtime `a275eee8` and test-only successor `c3c190c7`, the ASan/UBSan OFF/ON actual P10-vector oracle passed 2,000 independent detected-owner worlds and direct all-source-bit grid/linear comparisons. It included inclusive ±175/176/177 and clipped map edges, invalid-coordinate/owner fallback, stale-index outside-phase fallback, and a real `update_orders` pre-movement authorization witness. The hidden-Scarab fallback was source-inspected but not exercised with that optional staged actor. All 595 isolated inputs were verified before and after.
