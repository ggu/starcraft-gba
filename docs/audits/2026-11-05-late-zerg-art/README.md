# Late Zerg objective source art

The opt-in Z8 sprite-bank exporter can include the verified-ROM Init sprites for Z9's Khaydarin Crystal Formation (raw 173), Z10's Protoss Temple (174), and the trigger-created Khaydarin Crystal (219). They are compiled under `SC64_Z9_RUNTIME`; the ordinary Z8 and earlier profiles do not select these additions. A late build rejects an older bank without the complete set. Formation and Temple use the existing building art lookup; the crystal uses the ordinary raw-unit art lookup, replacing the generic Young Chrysalis fallback without changing the actor's rules or save data. Building drawing and the static-art cache use a larger conservative edge envelope for these two large source sprites.

The exporter follows the pinned ROM unit → flingy → sprite → image → GRP chain and existing source Init layer compositor. It fails closed if the three requested IDs do not all resolve or any source-opaque pixel maps to transparent index zero. In the verified USA ROM, raw 173 resolves to image 178 / GRP `00D/0B4` (64×64 canvas, 2,223 opaque pixels), raw 174 to image 207 / `00D/0D2` (112×80, 4,827 opaque), and raw 219 to image 396 / `00E/0A6` (14×14, 73 opaque). Their generated sprite pixels retained all those opaque pixels. The crystal GRP contains 17 frames; this change draws the source Init frame only. Deferred shadow rendering and subsequent source animation timing remain unqualified. No private art, screenshots or generated headers are tracked.

With locally prepared inputs, `tests/sc64_zerg_late_art.c` iterates every unit record in both authenticated late mission maps and every CreateUnit action in both generated programs. It requires a source sprite for visible identities and explicitly exempts raw 101 as the invisible map revealer and raw 214 as a start marker. It checks raw 173/174 building and raw 219 unit selection, verifies the pickup differs from Young Chrysalis, and compares actual rendered nontransparent pixels including offscreen-anchor clipping. The fixture runs with the Z10 production flag vector under ASan/UBSan. This is asset coverage and renderer evidence, not a mission-win, full source animation, physical hardware or performance claim.

On the verified local inputs, source exporter tests passed (24), the actual renderer/coverage fixture passed, and `make zerg-z9 zerg-z10` passed their normal ARM ROM verifiers.
