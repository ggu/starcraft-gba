# Optional tracer profile index cache

`SC64_TRACE_PROFILE_INDEX_CACHE` is an opt-in experiment requiring the existing duration cache and source VFX. A short positive duration occupies the low byte; an exact source profile index plus one can occupy the high byte. The renderer validates the actor, weapon, target mode and variant before using that index and otherwise calls the original resolver. Variant fallback results are deliberately not cached. Zero, long or unavailable durations use the original calculation. Cache storage is reset on world clear and legacy load, overwritten on slot reuse, and is not serialized. The experiment adds no storage or default product flag.

On source `4049136`, paired ARM builds used the same prepared normal Zerg/three-AI compiler vector, private input set, and ordinary-input tape (`0d79706afb77e58c958a6dd622a56843f611f4400bfa014bdbeb7db751f6ef2b`); only the candidate added the optional flag. Both linked under unchanged RAM guards, with BSS end `02036f44` and IWRAM end `03004cd8`. A port-free in-process replay with no guest writes matched all 90 sampled actor, building, fog, displayed RGB555 and frame checkpoints. This is sampled parity, not complete state equivalence.

For calls 8,021–9,020, total update/audio/render guest cycles were 715,874,119 without the flag and 708,887,202 with it (−0.976%); map cycles were 277,500,871 and 271,487,097 (−2.167%). This is one emulator workload with the same timing probe and presentation behavior, not a general performance, hardware or frame-rate claim. Full product, save and long-duration gameplay qualification remain open.

`make test-sc64-trace-profile-cache` runs asset-free sanitizer checks for duration boundaries, exact and fallback keys, invalid indexes, slot replacement and the index encoding limit. Prepared binaries, tapes, results, commands and link maps remain in ignored local artifacts.

The prepared-input full-TU host fixture `tests/sc64_trace_profile_cache_game.c` also passed under ASan/UBSan with the same Zerg feature vector adapted for `GBA_HOST`. It exercises real tracer creation, aging, duration lookup, slot replacement and clear, including 61 valid source profiles, corrupted-index fallback and two real variant-fallback profiles. The cached metadata reset used on legacy load is exercised directly; this is not a save/load continuation test. Its private compile vector, log and inputs must be supplied locally; no imported material is included.

A clean detached checkout of runtime `35794540b0d219b06bb6ed73abc87cd9fd749c06` with no prepared private inputs passed the source boundary check, `./dev doctor`, `./dev build`, `./dev test`, and `make test-sc64-trace-profile-cache`. The default suite ran 778 Python tests (23 skipped), a separate eight-test suite and its C fixtures. A fresh paired replay reproduced the same counters and 90 sampled checkpoints; 191 recorded source, generated-input, reused-object, tape, tool-driver and linker-script files had matching before/after hashes. That receipt does not cover every subordinate toolchain binary or library. Private logs and inputs remain local.
