# Rare actor dispatch and diamond placement probe

This isolated, default-off probe groups Reaver parent, Scarab, Guardian Cocoon and Egg order dispatch behind an inline type gate and a noinline ROM helper. Reaver falls through to ordinary orders; Scarab, Cocoon and Egg consume their turn. The separate existing `GBA_DIAMOND_ROM` option relocates `gfx_diamond`, including HUD/fallback uses. Neither option is activated in a release profile. This experiment uses staged shared-actor source based on `bd4dec9bdad88eb6d9ae70b90e3ea4f8908fd75c`; the dispatch change is `9d87a539`.

The unmodified staged Z7 ARM probe failed at IWRAM end `0x030052b8`; grouping Reaver, Scarab and Cocoon reduced it to `0x03005100`, and adding Egg reduced it to `0x030050e8`. Both still failed the strict `< 0x03005000` assertion. Combining Egg grouping with `GBA_DIAMOND_ROM` linked with IWRAM end `0x03004f10`, BSS end `0x0203d4b4`, leaving 240 bytes before the IWRAM guard. The other staged profiles linked with unchanged guards: Terran IWRAM `0x030047f8`, BSS `0x02036f1c`; P10 IWRAM `0x03004bb8`, BSS `0x020391e4`. Padded ROM SHA-256 hashes respectively are Z7 `b54cb31ccfb6a2cbc80f60fc081663c8fee0d4beed8157ac2de5380da5497ae0`, Terran `4eafa45cbb9d68e3d1f15bea355dedb45a3ff7dbdbc5744caeba2defda754ba3`, P10 `37bd722c133b9d7cac05a1136cade024bb521632e48987e99dbaf69c3b96a5ed`.

ASan/UBSan host button controllers and selected-journal plus independent feature-zero predecessor fixtures passed for Z7 and P10; the predecessor writers use release source `1e6e33aab3a9089815d1e8fbd5669e34b2c15e47`. An exhaustive host check for integer actor IDs -1 through 255 confirmed `sc64_race_raw_unit(type)==83` is equivalent to `type==U_REAVER` under the Z7 and P10 flag sets. The graphics clipping pixel oracle passed with and without `GBA_DIAMOND_ROM` in HOST. These are scoped tests, not campaign completion or physical-GBA evidence.

The Z7 compiler reports individual static frames of 56 bytes for `update_orders`, 32 for rare dispatch, and 88 for `gfx_diamond`; these do not prove nested stack bounds or runtime high-water. Paired timing for ordinary play and a diamond-heavy fallback/Cocoon-plus-HUD scene has not been established. The original staged Z7 build does not link under the unchanged guard, so it cannot serve as a valid directly paired emulator baseline without a separately justified memory-neutral comparison. Promotion remains blocked on paired correctness and cycle evidence, nested/runtime stack qualification, and the remaining campaign-save, art and performance gates.

A separate attempt to share `SC64_SCARAB_NONCOLLIDING` field checks in a noinline helper made the Z7 IWRAM end eight bytes larger (`0x03005210` versus `0x03005208` with the earlier Guardian-only probe), so it was discarded.
