# Scarab candidate graph prerequisite

Under the inactive `SC64_SCARAB_RUNTIME` gate, save and load preflight decode
the candidate through the profile's actual unit-row codec and check the
Scarab graph before SRAM write or live-world load commit. The validator uses
bounded local actor records and does not alter its candidate or live units.
It checks the raw-85 identity, parent raw-83 identity and matching live/source
owners, hidden and outside phases, selected status, parent/child links, unique
active training and outside rows, queue/capacity shape, active training HP and
no-slot detached flight. It accepts a live invincibility override rather than
forcing a source-type immunity. The scan is bounded by `MAX_UNITS` squared;
it adds no persistent actor storage.

`make test-scarab-save` is an optional prepared-input host fixture. It exercises
the existing production record writer/reader, valid progress 105, inside,
outside and detached records, a full actor pool, and checksum-valid malformed
records that the candidate validator and load reject. Its atomicity assertions
cover unit and building arrays, minerals, gas, frame and RNG. A separate run
of the same fixture under the historical `RACE_CAMPAIGN_FLAGS` checks the raw
signed-16 row path. No source game banks are generated by the fixture; its
P7 fact table is authored numeric data generated into an isolated run directory.

**This is not a complete save feature.** No Scarab namespace or migration is
implemented here; old records can reuse the same tag and coincidentally look
canonical. Before enabling gameplay, introduce a distinct namespace and
validate the interaction with roster and BC predecessor tags, variable
impact/Yamato envelopes, newest-slot ordering and atomic first-write migration.
Initialize all existing/new Reavers, wire source clock and lifecycle cleanup,
and validate every transfer, slot reuse and load path. The tests here do not
prove all-world atomicity, active impact/Yamato migration, normal-input UI,
flight or full gameplay. No production profile enables this experimental gate.
