# Research padding experiment (HOST only)

This is an isolated codec and synthetic-tag journal fixture, not a registered save format, runtime migration, or enabled upgrade. The source-level research facts and level helper are copied from commit 63dedd14. The 12-byte level representation stores six 2-bit families for each of eight source owners; the validator requires unused custom owners to be zero and limits Singularity to level one. Campaign identity and producer jobs need separate contextual authentication.

The normal release building records have reserved bits independent of whether the row is alive: compact records have seven high bits in byte 27 (bit 216 is used), and P7 typed records have five high bits in byte 24 (bits 192–194 are used). The experiment distributes 96 bits in row order, least-significant bit first. Compact uses 14 rows and leaves two bits zero; typed uses 20 rows and leaves four bits zero. All later reserved bits must be zero. A candidate tag is mandatory and must differ from every supplied predecessor tag. Existing tag handling and validators are unchanged. Decode checks all padding and owner constraints into local state, then normalizes to disjoint storage. Existing strict row decoders must validate those normalized rows before any world mutation. A checksum/tag is integrity and context evidence, not cryptographic authentication.

Actual release ELF layout measurements: Terran RaceSave 15856 bytes, Z7/Z9 16296, P10 16332, Showcase 14228. Journal payload maximum is 16368 bytes. Z7/Z9 with eight saved impact events and the 16-byte transport trailer exactly fill that maximum. P10 dynamically omits its 40-byte Yamato tail: eight, five, or two impact events fit with zero, one, or two active shots respectively. This experiment changes no sizes and preserves those combinations; it does not establish that any new producer state is legal. A fixed 12-byte append would reject previously legal states.

The real selector permits at most five recognized tags. Normal transport currently accepts two; a new candidate would require an explicitly chosen third tag and exact predecessor migration. Full actor stages already use five: a further combination requires a separately designed and tested compatibility architecture, not a silently expanded limit or dropped predecessor. Wrong-product/mission, malformed rows, paid jobs, source owner, capture, pending births, map identity, old/new slot fallback, and power-loss atomicity remain runtime admission work. The fixtures use synthetic records, not a genuine campaign migration. No private assets are included.

The HOST proof uses a separate normalized array (at most 4480 bytes), and is not an ARM allocation design. The current selector copies the original slot to the existing caller scratch, runs preparation, and rechecks the original SRAM record/checksum before publishing; ambiguous sequences can cause the winner to be prepared again. The current race adapter passes the `race_impact_record` storage and requires that exact pointer. A possible bounded integration would extract levels from this detached wire candidate, then normalize each building in a 25/28-byte temporary before each existing decoder, retaining the original scratch and its checksum. Every preflight and commit path that decodes a building must use that accessor, and context, temporary lifetime, nested stack frames, and ARM memory must be measured; the 12-byte packed levels and decoded 48-byte plan are additional state, not a demonstrated zero-cost allocation. Z9's measured normal EWRAM headroom is only 796 bytes, so a second full-record buffer is not acceptable without a separate resource proof.

Focused asset-free fixtures passed with clang AddressSanitizer and UndefinedBehaviorSanitizer under the shared native lock: `tests/sc64_protoss_research_padding_probe.c` exercises both actual strict row codecs with synthetic canonical facts, and `tests/sc64_protoss_research_padding_journal_probe.c` exercises the actual journal selector and writer with a synthetic full-size record. The latter proves fallback and preservation of the selected predecessor for this constructed case; it does not validate an actual RaceSave, impact event, Yamato shot, or transport trailer. Reproduce with `clang -std=c11 -DGBA_HOST -fsanitize=address,undefined -fno-omit-frame-pointer -g tests/sc64_protoss_research_padding_probe.c -o <output>`; the journal fixture additionally needs `-DSC64_WORKER_CARGO_KIND`. Run the outputs under the same lock.
