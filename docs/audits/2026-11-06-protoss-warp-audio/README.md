# Protoss construction audio source audit

This is a source comparison, not a native audibility or timing observation. No emulator or audio capture was run for this audit. The authenticated owned USA N64 ROM has SHA-256 `e7d21880c13953b45b8f8db6b2b6cfa02daa29d35b23799a967e96f21001b020`. Its sound table BOLT `014/000` has SHA-256 `51d3f44173e790cd1afef44a75ff1fbf4ff12c224c8d8bae33f731951bfaac4b`. The project extractor interprets the table as 1,144 PC-indexed sound IDs pointing to the ROM's ADPCM blob.

Pinned OpenBW revision `4b046d5f65302b10cb0a745f0fecd37ec85b20a8`, `bwgame.h` `order_PlaceProtossBuilding`, calls `play_sound(528, u)` on the worker only after successful creation, image replacement with Warp Anchor and assignment of IncompleteWarping. `order_IncompleteWarping` calls `play_sound(529, u)` on the building when remaining build time reaches zero, before later animation signals, image replacement, `WarpIn` and final building completion. This is an independently implemented PC behavior used to identify candidate N64-indexed clips; it does not prove the N64 calls them, or their audible timing.

The authenticated sound table's ID 528 has blob-relative offset `0x29469a`, length 24,456 bytes, and encoded stream SHA-256 `c7ed5605488c2e6e26f5e720ce4fe8343ddeec9b251b48ca0e64a0d11785c6db`. ID 529 has offset `0x29a622`, length 20,296 bytes, and encoded stream SHA-256 `62c5c5f959d554dfa5a068a1d1f2fde6b651592546e66d4ab33d96d78a52d7c0`. Neither is selected by the current unit-animation/advisor generator, and neither shares its exact offset/length with a currently selected clip. The existing private package's six-kind generated header does not provide explicit construction-start or these global completion clips. No proprietary streams or generated bank are included here.

The authenticated images table `00C/000` SHA-256 is `6b6123e2cc6771d96f914fc9bb92d34da17cc3319dc02e2db0cd10b4f3d2efdc`; iscript `012/002` SHA-256 is `f8e5f3d0fcca644470c37de65486e44b09eb30141eedccea3445afe7bc0f65bc`. Warp Anchor image 211 uses script 191, whose Init at offset `0x3666` has no sound opcode in the bounded linear/unconditional trace. The script's visual frames therefore do not themselves supply 528. The current `Scripts.unit_sounds` combines each building image's `Built` and `WarpIn` animation sound IDs into one `built` row, without following child overlays for that query. Pylon, Nexus, Gateway, Cybernetics Core and Forge have empty rows under that extractor. This is not proof every possible script path or native sound source is silent.

In `starcraft/game_audio.h`, the observer detects a friendly building's construction-to-complete transition and emits BUILT; if its row is empty, `game_audio_emit` substitutes WHAT. It has no building-creation sound event. The implementation below adds separate global clips and queues a start cue from a successful foundation allocation. Its completion cue is a GBA approximation of the earlier OpenBW timer-zero event, not evidence of exact N64 synchronization. Actual native audio capture remains necessary to establish N64 audibility and timing.

## Implementation and bounded checks

The optional bank now adds IDs 528 and 529 as two global cues; existing six unit sound kinds are unchanged. Against the delivered advisor bank, all 510 previous encoded SFX streams and 13 music streams matched byte for byte, their decoded lengths and frame counts matched, and all existing unit/advisor references remapped exactly around the inserted samples. Both banks use format 2, 10,512 Hz and 176 samples per frame. The private blob grew from 8,489,540 to 8,542,968 bytes; the new bank's header SHA-256 is `a9013631201e7af363d5ca63a5361d6ca4e42b0a1a12c8f5d8c681cbd1c8ab47` and blob SHA-256 is `daa9b49fd614ae9b4ef068f3b50f860ec46a5815cc4a91294c69da175fea6c81`. The delivered two-file bank did not retain its generator argv; equivalence is a direct output comparison, not a claim about that argv. The C bank decoder verified all 512 clips and 13 tracks against the new manifest.

A shared successful foundation allocation queues at most one visible friendly Protoss start cue for the next observer pass. The observer flushes it after resetting its effect budget; successful loads and new matches prime the observer and clear pending cues. Friendly Protoss completion selects 529 even offscreen, at the GBA construction transition. That event approximates the earlier OpenBW timer-zero cue, not the N64's proven timing. Existing Terran/Zerg completion and legacy-bank fallback remain in place. The focused default audio-on/off state hashes matched (`bd8675b3`), and the prepared P10-vector ASan/UBSan fixture checked generated sample selections, unfunded pending placement, saturation of the previous effect budget, same-frame slot reuse, cancellation, owner/camera filtering, completion once, real coincident-frame save/load, new-match priming, and Terran/Zerg completion behavior.

A separate bounded HOST run used title and custom-game menu inputs, then ordinary worker selection, mineral gathering and build controls. After startup it observed a Protoss human with one Nexus, four Probes and 50 minerals; it issued a Pylon order, selected bank sample 218 at game frame 153 for start, and sample 219 at frame 715 for completion, stopping at input tick 732. The ignored controller source SHA-256 is `3c95897d4a2dc60d7f20ba6d67c7818481e0747a36056bc60e5c04b5dcac6d84`, its input tape SHA-256 `df93db22d2346713129144127826b0e5a6f72d4e5c1913c899220fc9832df2e4`, and the receipt log SHA-256 `bb9c7253ef4c61ab84ae3588b06e807cd3b27237bf04d9f94a6dada2bcae8dba`. These are HOST sample-selection observations, not physical GBA or native N64 audio evidence. An earlier rendered campaign-controller attempt exited normally without either event because its economy built Terran structures; it does not support a Protoss audio claim.
