The shared source-shaped psi predicate changes the P3 controller's legal construction sites. At the same 2,392-update input prefix, its existing site selector chose `(1840,1304)` under the old circular field and `(1680,1288)` under the source-shaped field. The former is outside the source field. The original controller on the earlier power-only candidate lost at frame 90,211, while its unchanged old-circle baseline won at frame 42,597; these adaptive runs diverge, so the result alone does not establish an engine defect. A test-only first-assault threshold change from 32 to 40 also lost and was discarded.

A frame-10,000 replay of the earlier losing run matched its recorded aggregate state and showed six Probes idle together with a depleted mineral target, while the Gateway was complete, powered and progressing. This observation motivated a fresh comparison after the separately developed depleted-mineral continuation change; it does not by itself prove a single cause for the entire outcome.

Both satisfied the controller's mission-result checks, with no enemy buildings remaining and nine SIDE units. The runs used the same shared recovered input paths, compiler vector, and eight key inputs whose SHA-256 hashes were recorded before and after; this is not an exhaustive input manifest. Private traces and manifests remain local. The controller uses ordinary `game_update` inputs informed by host world-state observations; it is not a physical-input or hardware performance qualification. This comparison does not by itself qualify the other missions, source-owner identity, save migration or a Pylon overlay.
